# Bankruptcy-signals
Investigación de machine learning sobre las señales financieras que anticipan la quiebra empresarial: 6,819 empresas taiwanesas, 95 razones financieras y 5 modelos bajo la lupa (árbol, bagging, random forest, AdaBoost, XGBoost) evaluados con validación cruzada de 10 folds. Veredicto: XGBoost optimizado, F1 = 0.48.
